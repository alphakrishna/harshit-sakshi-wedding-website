# Harshit & Sakshi — Claude Asset Pack

## IMPORTANT
These are **cropped/soft-masked regions extracted from flattened generated illustrations**, not original independent illustration layers. The PNGs have transparent outer margins/edges but elements inside a crop may still include their original background. Removing a crop from the full image will NOT reveal a clean background beneath it. Avoid overlapping crops directly onto the original full reference at identical positions unless intended.

For production-grade parallax/animation, commission or generate separate truly transparent characters, petals, foreground arches, and background plates. This package is useful now for a working prototype and composition matching.

## Folder contents
- hero/: full reference, couple framed crop, divine blessing framed crop, temple arch, floral ornaments
- events/: full reference and four separate event cards
- story/: full reference and four photo-story crops
- closing/: full reference, couple framed crop, plaque crop

## Recommended implementation
1. Use real DOM/HTML text for headings, event dates, venue, and RSVP. Text inside a reference PNG is illustrative only.
2. Use framed card assets as images (`object-fit: contain`) on light ivory sections, not as transparent character sprites.
3. Animate elements individually with subtle transforms: photo scale <= 1.05, y 15-30px, opacity 0-1, duration 0.6-1.2s.
4. Keep religious imagery respectful; make animation gentle and optional music muted by default.
5. Avoid inventing wedding dates, venue, or specific love-story events. The story artwork includes speculative narrative not confirmed by the couple.
6. Provide a reduced-motion mode, image optimization, and accessible alternatives.
